# Selenium TestNG SQA Projects

Collection of Selenium WebDriver automation testing projects built using:

- Java
- Selenium WebDriver
- TestNG
- Maven
- XAMPP

---

# Projects Included

- Admin Profile Update
- Doctor Approval
- Doctor Approved
- Registration Check
- Selenium Practice
- Selenium FreeCodeCamp
- Test Request

---

# Requirements

Before running the projects, install:

- Java JDK 21
- IntelliJ IDEA
- Maven
- XAMPP
- Google Chrome

---

# How to Run

1. Clone the repository

```bash
git clone https://github.com/rakinirtiza/SELENIUM-TESTING-SQA-PROJECTS.git
```

2. Open the project in IntelliJ IDEA

3. Start XAMPP

- Apache → Start
- MySQL → Start

4. Import database into phpMyAdmin

5. Run the TestNG test files

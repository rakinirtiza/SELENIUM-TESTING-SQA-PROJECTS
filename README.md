# Selenium TestNG SQA Projects

Collection of Selenium WebDriver automation testing projects built using Java, TestNG, Maven, and XAMPP for software quality assurance practice.

---

# Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven
* XAMPP
* MySQL
* IntelliJ IDEA

---

# Projects Included

* Admin Profile Update
* Doctor Approval
* Doctor Approved
* Registration Check
* Selenium Practice
* Selenium FreeCodeCamp
* Test Request

---

# Requirements

Before running the projects, install the following tools:

* Java JDK 21
* IntelliJ IDEA
* Maven
* XAMPP
* Google Chrome

---

# Database Setup

1. Open XAMPP Control Panel

2. Start:

   * Apache
   * MySQL

3. Open phpMyAdmin

4. Create a database named:

hdb

5. Import the SQL file:

database/hdb.sql

---

# How to Run the Projects

1. Clone the repository

```bash
git clone https://github.com/rakinirtiza/SELENIUM-TESTING-SQA-PROJECTS.git
```

2. Open the project in IntelliJ IDEA

3. Reload Maven dependencies

4. Configure ChromeDriver if necessary

5. Run the TestNG test files
